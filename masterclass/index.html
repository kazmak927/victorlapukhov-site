Мастер-класс · Личный сайт с ИИ

До встречи —
три шага подготовки.

Выберите ChatGPT или Claude Code, подготовьте доступы с помощью ИИ — и на встрече сразу приступим к вашему сайту.

Показ будет в ChatGPT Work на GPT‑6 Astra. Альтернатива для участников — Claude Code с Opus 5 и уровнем xhigh. Достаточно одного варианта.

Начните за 2–3 дня до мастер-класса

  1. Выберите один из двух вариантов

    Возьмите ноутбук с зарядкой и телефон для кодов входа. Две подписки не нужны — подготовьте тот вариант, с которым будете работать.

    Вариант А. ChatGPT Work · GPT‑6 Astra

    Установите или обновите настольное приложение ChatGPT. Нужна действующая подписка Plus или выше; базовая цена Plus — $20 в месяц.

    В новом чате вверху переключите режим на Work. Выберите локальную работу — Work locally — и модель GPT‑6 Astra (может называться Astra).

    Убедитесь, что он доступен с вашего компьютера (вы знаете, о чем речь). Отправьте короткое сообщение и проверьте оставшийся лимит для практики. Название выбранной модели проверьте в интерфейсе.

    Вариант Б. Claude Code · Opus 5 · xhigh

    Обновите настольное приложение Claude, войдите с подпиской Pro или Max и откройте вкладку Code. Выберите локальную работу, папку для сайта, модель Opus 5 и уровень усилия Extra high (xhigh).

    В консольной версии модель выбирается через /model, уровень — командой /effort xhigh. Проверьте выбранные настройки, отправьте пробное сообщение и убедитесь, что лимита хватит на практику. Настройка модели и усилия.

    Интерфейс Claude отличается от показа ведущего. Этот вариант подготовлен по документации; полный запуск сайта через Claude ещё не проверен. Пройдите проверку доступов ниже до встречи.

  2. Попросите выбранного ИИ помочь с подготовкой

    Дальше подготовка общая. Скопируйте запрос в ChatGPT Work или Claude Code. Агент проверит инструменты своего приложения и поможет с настройкой. Сначала используем то, что уже работает. В ChatGPT встроенный браузер входит в приложение, Computer Use тоже может быть уже подключён.

    Помоги подготовиться к мастер-классу по созданию личного сайта на Timeweb Cloud. Моя система: [macOS или Windows]. Домен: [адрес или «пока нет»]. Сначала проверь управление браузером уже доступными инструментами: открой example.com и перейди по ссылке Learn more. Затем помоги войти в GitHub и Timeweb Cloud и проверить домен, его администратора и баланс. Подключи Timeweb Cloud MCP к приложению, в котором мы сейчас работаем, если он ещё не подключён, по официальной инструкции https://timeweb.cloud/docs/ai-agents/timeweb-cloud-mcp. Выполни доступные шаги сам; когда нужны мой вход, личные данные или подтверждение, остановись и объясни одно следующее действие. Если инструмент недоступен, сообщи об этом, не выдавай проверку за выполненную. Токен предложи ввести в настройки авторизации или защищённый локальный ввод, не в чат. Перед оплатой домена покажи цену и дождись подтверждения. Платное приложение и репозиторий пока не создавай, сайт не публикуй, существующие DNS-записи не меняй. В конце перечисли, что проверено и что осталось сделать. Пароли и токены не выводи.

    Что понадобится подтвердить самому:

    • Аккаунты. Войти или зарегистрироваться в GitHub и Timeweb Cloud. Бесплатного GitHub достаточно. Входите в том браузере, который откроет выбранный агент.
    • Администратор домена. До покупки домена обязательно создать запись о владельце в Timeweb: «Домены и SSL» → «Администраторы» → «Добавить». Для личного сайта укажите себя. Для физлица и зоны .RU или .РФ пройдите идентификацию через Госуслуги. Если запись уже есть, используйте её.
    • Домен и баланс. Выбрать и оплатить домен, проверив цены регистрации и продления. Для учебного размещения сайта достаточно положить 500 ₽ на баланс Timeweb Cloud. Стоимость самого домена учитывайте отдельно.
    • Разрешения и авторизация. Подтвердить запросы системы и ввести API-токен Timeweb в настройки подключения, если это потребуется.

    Домен зарегистрируйте хотя бы за сутки: обновление DNS может занять 3–24 часа. Файлы сайта, репозиторий и приложение для размещения создадим вместе на встрече.

    Уже есть домен?

    В зависимости от домена, регистратора и места управления DNS варианты подключения могут сильно отличаться. На встрече покажем именно Timeweb Cloud: у него есть готовое подключение для ИИ-агентов — MCP. Наличие такого подключения у других провайдеров не гарантируется.

    Сообщите ведущему заранее, где зарегистрирован домен. Если на нём работают сайт или почта, подключение согласуем с сохранением существующих записей, включая MX и SPF.

    Если ChatGPT просит настроить MCP вручную

    Настройки вводятся в настольном приложении ChatGPT: «Настройки» → «Серверы MCP» → «Добавить сервер». Имя — timewebCloud, тип — Streamable HTTP, адрес — https://timeweb.cloud/api/v1/mcp.

    API-токен создаётся в панели Timeweb Cloud в разделе «API и Terraform». Для авторизации используется заголовок Authorization со значением Bearer ВАШ_API_ТОКЕН. Вводите его только в настройки авторизации, не в переписку. Если видите другие поля, попросите ChatGPT помочь с вашей версией интерфейса.

    Сохраните подключение, нажмите Restart («Перезапустить») и повторите проверку в новом чате Work. Настройки MCP в ChatGPT · Инструкция Timeweb.

    Если для Claude Code нужна помощь с MCP

    Попросите Claude выполнить раздел «Настройка Claude Code» в инструкции Timeweb. Для описанного там способа нужна консольная версия Claude Code; агент может проверить её наличие и подготовить конфигурацию.

    Адрес сервера — https://timeweb.cloud/api/v1/mcp. Токен задаётся локально через TIMEWEB_CLOUD_TOKEN, без отправки в чат. После настройки попросите проверить соединение. Подключение, сделанное в ChatGPT, не означает, что оно уже настроено в Claude.

    Если управление браузером в ChatGPT не работает

    Попросите ChatGPT проверить встроенный браузер через @Browser. Если нужен Computer Use, откройте в приложении «Плагины» → Computer Use и выберите «Включить» или «Установить», только если это предлагается. На Mac подтвердите системные разрешения по запросу. Если проверка уже проходит, этот шаг пропустите.

  3. Соберите материалы о себе

    В одну папку: фотографию, 5–10 предложений о себе, три направления вашей работы, 2–3 достижения, публичные контакты и один-два примера сайтов, которые вам нравятся.

    Подумайте, для кого ваш сайт и какое действие должен совершить посетитель.

Вы готовы к встрече

Выбранная модель — GPT‑6 Astra или Opus 5 с xhigh — отвечает с вашего компьютера, лимит для практики есть. Агент управляет браузером и видит Timeweb через MCP. Аккаунты доступны, домен зарегистрирован на вашего администратора, баланс пополнен, материалы собраны.

Если что-то не получилось, пришлите ведущему сообщение агента о проблеме без паролей и токенов. Разберёмся до занятия.

О расходах

Одна выбранная подписка — ChatGPT или Claude, — домен и размещение оплачиваются отдельно. 500 ₽ — запас на учебное размещение. В нашем запущенном примере App Platform: 1 ₽/мес. за диск + 0,000495 ₽ за запрос, около 5,95 ₽/мес. при 10 000 запросов. На встрече проверим актуальный тариф и зададим лимит запросов.
