Мастер-класс · Личный сайт с ИИ

До встречи —
шесть шагов подготовки.

На занятии будем создавать сайт-визитку на вашем домене с помощью ИИ. Подготовьте аккаунты и материалы заранее, чтобы посвятить наш час самому сайту.

Начните за 2–3 дня до мастер-класса

  1. Проверьте подписку и GPT‑6

    Возьмите ноутбук с зарядкой и телефон для кодов входа. Установите настольное приложение ChatGPT, войдите в аккаунт и откройте рабочий режим Work/Codex.

    • Подписка — ChatGPT Plus или выше. Это минимальное требование нашего мастер-класса. Базовая цена Plus — $20 в месяц; итоговую сумму проверьте при оплате. Подписка должна действовать в день занятия.
    • Модель — именно GPT‑6 Astra (в меню может называться Astra). Откройте выбор модели в новом чате и убедитесь, что она доступна и выбрана.
    • Проверьте оставшийся лимит использования: его должно хватать на практику. Подписку и модель проверьте сами в интерфейсе — ответ ИИ о собственной версии не заменяет эту проверку.

    Если GPT‑6 Astra или рабочий режим недоступны, сообщите ведущему до занятия. Доступ зависит от аккаунта и версии приложения; одной оплаты подписки недостаточно для проверки готовности.

  2. Включите Computer Use и браузер

    Откройте «Плагины» → Computer Use, установите плагин или нажмите «Включить», если он уже установлен. Включите его сервер и навык. На macOS предоставьте приложению разрешения «Запись экрана» и «Универсальный доступ» по запросу системы.

    Для Chrome откройте «Настройки» → Computer Use → Chrome → «Установить» и добавьте расширение ChatGPT в браузер. Вернитесь в настройки: рядом с браузером должно появиться «Управлять» (Manage). Используйте тот профиль Chrome, где установлено расширение.

    Выберите браузер через @Chrome и проверьте, что агент может открыть страницу и нажать ссылку. На Windows во время работы агента оставляйте окно видимым. Инструкция Computer Use · Подключение браузера.

  3. Войдите в два сервиса

    Создайте собственные аккаунты в GitHub и Timeweb Cloud. GitHub будет хранить файлы сайта, Timeweb — размещать его в интернете. Для GitHub достаточно бесплатного аккаунта.

    Откройте оба сервиса и войдите в них в браузере, которым сможет управлять ИИ. Проверьте доступ к своей почте и кодам подтверждения. Файлы сайта и репозиторий создадим на занятии.

  4. Создайте администратора и купите домен

    Сначала обязательно создайте администратора домена: в Timeweb Cloud откройте «Домены и SSL» → «Администраторы» → «Добавить». Администратор — человек или организация, на чьи данные регистрируется домен. Для личного сайта укажите себя; если подходящая запись уже есть, используйте её.

    Для физлица и домена .RU или .РФ выберите «Добавить через Госуслуги» и завершите идентификацию. Для других зон заполните предложенную форму. Данные вводите самостоятельно в панели сервиса. Пошаговая инструкция Timeweb.

    Затем откройте «Домены и SSL» → «Купить домен», выберите адрес и созданного администратора, проверьте цены регистрации и продления и оплатите. Завершите все запрошенные проверки и подтверждение почты. Сделайте это минимум за сутки: обновление DNS может занять 3–24 часа.

    После покупки оставьте на балансе средства для размещения сайта. Используем App Platform; приложение создадим вместе на занятии.

    Уже есть домен? Сообщите об этом ведущему заранее. Если на нём работает сайт или почта, сначала согласуем подключение с сохранением существующих настроек.

  5. Подключите Timeweb к ИИ

    Добавьте Timeweb Cloud MCP в подключения приложения — через него агент сможет работать с вашим облачным аккаунтом. Для авторизации нужен API-токен из раздела «API и Terraform» в Timeweb Cloud.

    Токен вводите только в настройках авторизации подключения. Не отправляйте его в переписку, общий документ или репозиторий. Если настройка вызывает трудности, обратитесь к ведущему до мастер-класса.

    Параметры подключения

    Тип: Streamable HTTP («Потоковая передача HTTP»).
    Адрес: https://timeweb.cloud/api/v1/mcp
    Заголовок: Authorization
    Значение: Bearer ВАШ_API_ТОКЕН

    Название меню зависит от версии приложения. Если поле называется «переменная окружения для токена», оно ожидает имя переменной, а не сам токен. Сверьтесь с официальной инструкцией Timeweb.

  6. Соберите материалы о себе

    Сложите в одну папку то, что готовы опубликовать:

    • одну качественную портретную фотографию;
    • 5–10 предложений о себе и своей работе;
    • три направления вашей экспертизы и 2–3 достижения;
    • контакты и ссылки для посетителей сайта;
    • один-два примера сайтов, которые вам нравятся.

    Ответьте для себя на три вопроса: кому нужен мой сайт, что посетитель должен обо мне понять и какое действие совершить?

Последняя проверка

Отправьте агенту этот текст, подставив свой домен:

Готовлюсь к мастер-классу по созданию личного сайта. Мой домен: [ваш домен]. Проверь подключение Timeweb Cloud MCP, наличие домена и назначенного ему администратора. Проверь доступность Computer Use и управления браузером, затем мои открытые аккаунты GitHub и Timeweb Cloud. Укажи, чего не хватает для записи файлов в GitHub и публикации сайта через App Platform. Ничего не создавай, не покупай и не меняй настройки. Пароли и токены не выводи.

Вы готовы, когда подписка Plus или выше активна, GPT‑6 Astra выбрана, Computer Use и браузер работают, администратор создан и домен зарегистрирован, доступ к сервисам проверен, а фото и текст лежат в одной папке. Если проверка выявила проблему — пришлите ведущему её описание без паролей и токенов.

Что оплачивается

Домен — отдельно, обычно за год; цена зависит от выбранного адреса. Размещение — по тарифу App Platform. В нашем проверенном примере: 1 ₽/мес. за диск и 0,000495 ₽ за запрос, то есть около 5,95 ₽/мес. при 10 000 запросов. Запрос — это обращение за страницей или файлом, а не отдельный посетитель.

На занятии зададим лимит расходов через ограничение числа запросов: при достижении лимита сайт приостанавливается. Для участия нужна отдельная подписка ChatGPT Plus ($20/мес. по базовому тарифу) или выше. Актуальные суммы проверяйте перед оплатой.
